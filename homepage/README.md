# Home Security AI — Homepage

A lightweight, responsive project landing page inspired by the visual direction of [CyberShield by ThemeWagon](https://themewagon.com/themes/cybershield/).

## Preview

Open `index.html` directly in a browser, or run a local static server:

```bash
python3 -m http.server 8080
```

Then visit http://127.0.0.1:8080.

## Files

- `index.html` — landing page structure and project content
- `styles.css` — responsive dark security theme and diagrams
- `script.js` — mobile navigation and current year

The page uses original markup and styles, Google Fonts, and CSS/SVG illustrations. It does not bundle the CyberShield source package.
